Schleim OS 3.22.0 / Schleim Browser Android alpha32

Build and publish versionCode 32 / versionName 0.1.0-alpha32 and Extension 3.22.0. Preserve GeckoView, the #251205 UI, tabs, local history, bookmarks, encrypted password manager, guest mode, add-ons and the fixed NextDNS TRR-only resolver https://dns.nextdns.io/36e7f3/Schleim-Browser.

VPN:
- WireGuard is integrated in the Schleim Browser Android menu through the existing tunnel library and Android VpnService consent; do not build a separate VPN APK.
- VPN panel supports status, selecting an imported profile, connect/disconnect, importing .conf and refreshing the credential-free repository catalog.
- Tunnel is app-scoped to Schleim Browser. Extension VPN tile uses GeckoView native messaging to open the Android panel; desktop extensions cannot start Android VpnService.
- Import personal full WireGuard .conf files generated from the user's Proton account. Store profiles encrypted with Android Keystore AES-GCM. Never publish private keys or package them in APK assets.
- Free location catalog is repository-maintained and refreshed by the app. It is not a live Proton availability API. Public templates have no PrivateKey.
- Obsolete .ovpn files have been removed. No separate VPN APK was present.

Universal APK:
- Bundle GeckoView ABIs ARMv7 (armeabi-v7a), ARM64 (arm64-v8a) and x86_64 in one APK.
- 32-bit x86 is not supported by the pinned GeckoView AAR. Minimum Android API 26 / Android 8.0; Android 7 is not supported.
- Validate the three supported native ABI folders, APK signature, package ID and bundled extension.
