Schleim OS 3.22.0 Android browser release

Build and validate Schleim Browser 0.1.0-alpha32 (versionCode 32). Preserve existing GeckoView browser features, the dark brown UI #251205, tabs, history, bookmarks, encrypted password manager, add-on support and the exact NextDNS DoH resolver configuration.

Integrate WireGuard directly into Schleim Browser's Android menu. Do not create or publish a separate VPN app. The native VPN panel must support status, selecting imported location profiles, connecting/disconnecting and importing current personal WireGuard .conf files. Encrypt imported profiles with Android Keystore AES-GCM and route the tunnel only to the Schleim Browser package. Keep private WireGuard keys out of public repository files, extension files, server catalogs and APK assets. The public location catalog is refreshed from the repository when the VPN panel opens. Document that Proton's former unauthenticated public server-list endpoint is unavailable and personal current configurations must be imported from the user's own Proton account.

Connect the original browser extension's VPN tile to the Android native panel through the GeckoView native-message bridge. Desktop browsers must show a clear fallback; do not claim the extension itself implements Android VpnService.

Remove obsolete OpenVPN .ovpn profiles and any separate VPN APK if present. Keep sanitized .conf location metadata and servers.json. Produce one universal APK with the native ABIs supplied by the pinned GeckoView/WireGuard libraries: ARMv7, ARM64 and x86_64. 32-bit x86 is not provided by the pinned GeckoView AAR. Keep minSdk 26 and document that universal ABI support does not mean support for every Android version.

Update the Android Studio template, Extension template, German/English/Dutch documentation and Easy Language documentation. Include VPN limitations, personal-profile import, private-key safety, browser-only tunnel behavior and ABI compatibility in release notes.
