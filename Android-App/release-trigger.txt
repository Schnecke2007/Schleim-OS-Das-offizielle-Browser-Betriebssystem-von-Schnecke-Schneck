Schleim OS 3.21.0 Android browser release

Build and validate Schleim Browser 0.1.0-alpha31 (versionCode 31). Preserve all existing browser features, the #251205 dark brown UI, Mozilla GeckoView, tabs, local history, bookmarks, encrypted password manager, add-on support and the fixed NextDNS DNS-over-HTTPS resolver. The DNS resolver must remain exactly https://dns.nextdns.io/36e7f3/Schleim-Browser in TRR-only mode and must not be shown by hostname in Settings.

Add a dedicated Details button for every installed extension in the Android extension manager. Populate the detail view only from actual GeckoView WebExtension metadata for that extension: description, version, developer, homepage, options page, rating/review metadata when present, required and optional permissions, host origins and data-collection permissions. Allow optional permissions to be individually granted or revoked through GeckoView's WebExtensionController APIs. Open an extension-specific options page only when GeckoView reports one.

For compatible non-built-in extensions, provide the Run in private windows control backed by WebExtensionController.setAllowedInPrivateBrowsing. Respect an extension manifest that explicitly forbids private use. Display the manifest private-mode setting where available. Identify the proxy permission when an extension requests it, but do not claim this creates a system-wide VPN tunnel or guarantees that a VPN extension protects private traffic. Persist the allowedInPrivateBrowsing setting in the encrypted browser profile backup and restore it on another device along with add-on enabled/disabled state.

Update German, English and Dutch Android documentation and Easy Language guides. Create release notes in all three languages plus Easy Language in each language. Explain that an extension may have no options page and that private browsing is not the same as a system-wide VPN.

Package the Extension, neutral Extension template, Android APK alpha31, Android Studio template, update JSON and SHA-256 sums. Publish the complete release v3.21.0 only after the APK and templates pass build validation, then verify the published assets, metadata, checksums and APK signature.

Requested release: 2026-11-25 — Schleim Browser alpha31 with per-extension detail screens, optional-permission management, private-window support and profile backup/restore integration.
