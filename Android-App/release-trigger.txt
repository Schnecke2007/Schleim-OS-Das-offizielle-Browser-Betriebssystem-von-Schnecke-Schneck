Schleim Browser Android VPN release

Build and validate Schleim Browser 0.1.0-alpha33 (versionCode 33) with native WireGuard VPN controls directly in the Android browser menu.

Required VPN capabilities:
- Native WireGuard tunnel through Android VpnService; no separate VPN app.
- Connect/disconnect toggle and server/profile switching without leaving the browser menu.
- Import personal WireGuard .conf profiles from Android's file picker.
- Remove comment metadata and source filenames on import; assign neutral local profile names.
- Encrypt all imported profile data locally with Android Keystore AES-GCM. Never commit personal .conf files, private keys or PresharedKeys, and never bundle user credentials in the APK or public template.
- Keep the tunnel restricted to the Schleim Browser package.
- Show live download (received) and upload (sent) rates in Mbit/s plus cumulative received/sent MB using WireGuard tunnel statistics.
- Keep the public location catalog as reference metadata only; do not present it as live provider availability.

Preserve all unrelated browser features, including GeckoView browsing, tabs, history, bookmarks, encrypted password manager, add-on support, downloads, printing, private browsing and DNS-over-HTTPS.

The Android APK must be universal for ARMv7 (armeabi-v7a), ARM64 (arm64-v8a) and x86_64. 32-bit x86 is not supplied by the pinned GeckoView build. Keep minSdk 26 (Android 8.0+).

Publish the new Android build as Schleim OS v3.22.1. Verify the APK build, signing, universal ABIs, generated Android Studio template, checksums and release assets. Do not overwrite v3.22.0.

CI validation adjustment: the documentation assertion runs against lowercase text and checks for the normalized token mbit/s.

Launcher build robustness: use the original Android PNG when checked out; otherwise fall back to the repository's extension/assets/icons/icon-512.png. The build must still validate the generated launcher icon.

Extension validation adjustment: the Android VPN tile is intentionally available in the new-tab page and opens the native VPN panel through the browser bridge. Legacy OpenVPN references remain prohibited.
