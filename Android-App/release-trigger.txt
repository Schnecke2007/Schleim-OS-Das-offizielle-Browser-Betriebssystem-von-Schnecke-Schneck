Schleim OS 3.22.0 Android browser release

Build and validate Schleim Browser 0.1.0-alpha32 (versionCode 32) without any VPN integration. Preserve all unrelated browser features, including GeckoView browsing, tabs, history, bookmarks, encrypted password manager, add-on support, downloads, printing, private browsing and the existing DNS-over-HTTPS configuration.

The Android APK must be universal for the ABIs supplied by the pinned GeckoView libraries: ARMv7 (armeabi-v7a), ARM64 (arm64-v8a) and x86_64. 32-bit x86 is not supplied by the pinned GeckoView build. Keep minSdk 26 (Android 8.0+).

No VPN menu, VPN tile, WireGuard dependency, VPN service, server catalog, WireGuard profile, VPN native bridge or VPN-related documentation should remain in the application or templates.

Build and validate the APK, both Extension archives, the Android Studio template, update JSON, SHA-256 sums and APK signature. Update the existing v3.22.0 GitHub Release in place; preserve the existing tag and create the release only if it is absent. Verify all published assets and checksums.
