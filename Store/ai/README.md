# KI & Chatbots (ai)

Öffentliches App-Verzeichnis der Kategorie **KI & Chatbots** im Schleim-Store.

**Veröffentlichte Apps:** 2

- **ChatGPT** — KI-Assistent für Fragen, Ideen, Texte und kreative Aufgaben. ([JSON](./chatgpt-web.json))
- **Claude** — Claude ist ein KI-Assistent für Fragen, Texte, Ideen und Programmierhilfe. Die Webseite claude.ai wird in einem neuen Browser-Tab geöffnet. ([JSON](./claude.json))

[Zur Store-Übersicht](../README.md)


**Zugriff in Schleim OS:** Der Schleim-Store wird erst nach Anmeldung mit einem Schleim-Konto freigeschaltet. Dieser öffentliche Katalog bleibt direkt auf GitHub sichtbar. Die Cloud-Sicherung befindet sich ausschließlich unter **Einstellungen → Schleim-Konto**.
