# KI & Chatbots (ai)

Öffentliches App-Verzeichnis der Kategorie **KI & Chatbots** im Schleim-Store.

**Veröffentlichte Apps:** 2

- **ChatGPT** — KI-Assistent für Fragen, Ideen, Texte und kreative Aufgaben. ([JSON](./chatgpt-web.json))
- **Claude** — Claude ist dein intelligenter KI-Assistent direkt in Schleim OS. Egal ob du kreative Texte schreiben, komplexe Fragen klären, Code programmieren oder schnelle Ideen für deine Projekte sammeln möchtest – Claude unterstützt dich zuverlässig bei jeder Aufgabe und sorgt für maximale Produktivität auf deinem System. ([JSON](./claude.json))

[Zur Store-Übersicht](../README.md)
