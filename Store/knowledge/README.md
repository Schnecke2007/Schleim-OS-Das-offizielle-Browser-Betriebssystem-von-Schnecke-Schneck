# Wissen (knowledge)

Öffentliches App-Verzeichnis der Kategorie **Wissen** im Schleim-Store.

**Veröffentlichte Apps:** 2

- **Google** — Google ist eine Suchmaschine, mit der du im Web recherchieren und navigieren kannst. ([JSON](./google.json))
- **Wikipedia** — Wissen und Hintergrundinformationen in einer freien Enzyklopädie finden. ([JSON](./wikipedia-web.json))

[Zur Store-Übersicht](../README.md)


**Zugriff in Schleim OS:** Der Schleim-Store wird erst nach Anmeldung mit einem Schleim-Konto freigeschaltet. Dieser öffentliche Katalog bleibt direkt auf GitHub sichtbar. Die Cloud-Sicherung befindet sich ausschließlich unter **Einstellungen → Schleim-Konto**.
