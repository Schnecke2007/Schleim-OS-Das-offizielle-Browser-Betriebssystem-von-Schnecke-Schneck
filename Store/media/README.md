# Medien (media)

Öffentliches App-Verzeichnis der Kategorie **Medien** im Schleim-Store.

**Veröffentlichte Apps:** 6

- **Deezer** — Streame Musik von überall, wo du willst ([JSON](./deezer.json))
- **Instagram** — Entdecke Instagram! Gehe live, schaue dir lustige Videos an und gestalte dein eigenes Profil, um ein erfolgreicher Content Creator zu werden. ([JSON](./instagram.json))
- **Sonos** — Offizielle Sonos-Web-App; wird wie andere Store-Web-Apps in einem neuen Browser-Tab geöffnet ([JSON](./sonos-control.json))
- **Spotify** — Musik und Podcasts direkt im Browser anhören ([JSON](./spotify-web.json))
- **TikTok** — Entdecke Kurzvideos, Creator und aktuelle Trends auf der offiziellen TikTok-Plattform. TikTok wird in einem neuen Browser-Tab geöffnet. ([JSON](./tiktok.json))
- **YouTube** — Videos, Musik, Tutorials und Unterhaltung entdecken ([JSON](./youtube-web.json))

[Zur Store-Übersicht](../README.md)


**Zugriff in Schleim OS:** Der Schleim-Store wird erst nach Anmeldung mit einem Schleim-Konto freigeschaltet. Dieser öffentliche Katalog bleibt direkt auf GitHub sichtbar. Die Cloud-Sicherung befindet sich ausschließlich unter **Einstellungen → Schleim-Konto**.
