# 🛠️ Schleim OS – Fehlerbehebung

Hier findest du Lösungen für häufige Probleme bei Installation, Anmeldung und Verwendung von Schleim OS 3.12.0.

| Problem | Mögliche Lösung |
|---|---|
| **Die ZIP-Import-Schaltfläche fehlt.** | Prüfe, ob dein Browser den direkten Import von ZIP-Erweiterungen unterstützt. Die Schaltfläche kann beispielsweise **„From .zip/.crx/.user.js“** heißen. |
| **Die ZIP-Datei wird nicht angezeigt.** | Lade über GitHub mit **Code → Download ZIP** das vollständige Repository herunter. Prüfe anschließend deinen Download-Ordner. |
| **Die Installation meldet einen Fehler.** | Wähle die vollständige Repository-ZIP. Entpacke sie vorher nicht und ändere sie nicht. |
| **Schleim OS erscheint nicht in einem neuen Tab.** | Prüfe in der Erweiterungsverwaltung, ob Schleim OS installiert und aktiviert ist. Öffne danach einen neuen Tab. |
| **Änderungen werden nicht angezeigt.** | Öffne die Erweiterungsverwaltung und lade Schleim OS neu. Öffne anschließend einen neuen Tab. |
| **Der Schleim-Store ist gesperrt.** | Der Store braucht eine Anmeldung mit dem Schleim-Konto. Wähle **Mit GitHub verbinden**, installiere die App **Schleim OS Account** und fahre anschließend mit dem Gerätecode fort. |
| **GitHub erkennt die App-Installation nicht.** | Prüfe, ob du die GitHub-App für dasselbe Konto installiert hast, mit dem du dich anmeldest. Schleim OS prüft nach der Geräteautorisierung erneut. Öffne bei Bedarf den Installationslink erneut und starte die Anmeldung noch einmal. |
| **Der Gerätecode wird nicht kopiert.** | Der Code bleibt sichtbar. Verwende **Code kopieren** oder markiere den Code und kopiere ihn manuell. Öffne danach den Link zur GitHub-Gerätefreigabe. |
| **Die Cloud-Sicherung fehlt.** | Öffne **Einstellungen → Schleim-Konto**. Die Sicherung gibt es nur dort, nicht im Schleim-Store. |
| **Einstellungen fehlen nach einem Browserwechsel.** | Öffne **Einstellungen → Schleim-Konto**, melde dich mit demselben GitHub-Konto an und wähle **Cloud-Sicherung wiederherstellen**. |
| **Externe Inhalte fehlen oder bleiben leer.** | Prüfe deine Internetverbindung. Manche Anbieter blockieren die Einbettung ihrer Seiten in andere Websites. |
| **Die Installation funktioniert in Chrome für Android nicht.** | Chrome für Android unterstützt keine regulären Chrome-Erweiterungen. Verwende einen Android-Browser, der Erweiterungen und direkten ZIP-Import unterstützt. |

## Weitere Hilfe

Wenn das Problem weiterhin besteht, melde es bitte über [GitHub Issues](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/issues). Beschreibe dabei den Browser, die Version, die Schritte und die Fehlermeldung. Teile keine Passwörter oder vertraulichen Zugangsdaten.
