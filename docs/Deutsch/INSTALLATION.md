# 📥 Schleim OS – Installationsanleitung

Diese Anleitung beschreibt die lokale Installation der Schleim-OS-Browser-Erweiterung in kompatiblen Chromium-Browsern.

## 1. ZIP-Datei von GitHub herunterladen

1. Öffne das [Schleim-OS-GitHub-Repository](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck).
2. Klicke oben auf die grüne Schaltfläche **Code**.
3. Wähle **Download ZIP**.
4. Speichere das ZIP-Archiv auf deinem Gerät.
5. Entpacke das ZIP-Archiv vollständig.
6. Suche den Erweiterungsordner, in dem die Datei `manifest.json` direkt liegt. Genau diesen Ordner musst du später im Browser auswählen.

## 2. Google Chrome

1. Öffne `chrome://extensions`.
2. Aktiviere oben rechts den **Entwicklermodus**.
3. Klicke auf **Entpackte Erweiterung laden**.
4. Wähle den entpackten Erweiterungsordner aus, in dem `manifest.json` direkt liegt.
5. Öffne einen neuen Tab. Schleim OS sollte jetzt starten. 🎉

## 3. Microsoft Edge und Brave

- **Microsoft Edge:** Öffne `edge://extensions`.
- **Brave:** Öffne `brave://extensions`.
- Aktiviere den Entwicklermodus, wähle **Entpackt laden** bzw. **Load unpacked** und danach den entpackten Erweiterungsordner mit der direkt darin liegenden Datei `manifest.json`.

> ⚠️ **Wichtig:** Die Funktion **„Entpackte Erweiterung laden“** erwartet einen Ordner, keine ZIP-Datei. Für die lokale Installation über den Browser-Entwicklermodus muss das GitHub-ZIP daher zuerst entpackt werden. Wähle danach den Ordner aus, in dem `manifest.json` direkt liegt.

## 4. Nach der Installation

Öffne einen neuen Browser-Tab. Wenn Schleim OS nicht erscheint, prüfe die Erweiterungsverwaltung und folge der [Fehlerbehebung](TROUBLESHOOTING.md).
