# Schleim OS 3.16.0 – Android-Browser-Veröffentlichung

Schleim OS ist jetzt zusätzlich zur Browser-Extension als Android-App verfügbar.

## Neu

- Neue native Android-App **Schleim Browser** auf Basis von Mozilla GeckoView.
- Die originale Schleim-OS-Extension ist in die Android-App eingebunden.
- Native Browserleiste mit Adress-/Suchfeld, Navigation, Startseite und Tabs.
- Browser-Menü mit Downloads, XPI-Erweiterungen, Desktop-Ansicht und Android-Einstellungen.
- Android-Dateiauswahl und Speicherdialoge.
- Android-Studio-Projekt als separates ZIP mit neutralen Platzhaltern im Template-Ordner Android-App.
- Neue Anleitungen und Dokumentation in Deutsch, Englisch und Niederländisch.

## Downloads im Release

- Schleim-OS-Extension.zip: normale Browser-Extension.
- Schleim-Browser-Android-0.1.0-alpha22.apk: Android-Browser.
- Browser-OS-Extension-Template.zip: neutrales Extension-Template.
- Schleim-Browser-Android-Studio-Template.zip: neutrales Android-Studio-Projekt.
- Schleim-OS-SHA256SUMS.txt: SHA-256-Prüfsummen der Release-Dateien.

## Kompatibilität und Hinweise

- Android 8.0 oder neuer, 64-Bit-ARM (arm64-v8a).
- Kamera- und Mikrofonaufnahme sind in der Android-App deaktiviert.
- Die Android-App wird derzeit als Debug-APK erstellt. Ein Update kann deshalb eine Deinstallation der alten Version erfordern.
- Die Android-App und die Browser-Extension werden getrennt aktualisiert.
