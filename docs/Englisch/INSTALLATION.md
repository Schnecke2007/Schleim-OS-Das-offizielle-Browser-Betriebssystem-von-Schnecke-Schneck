# 📥 Schleim OS – Installation Guide

This guide explains how to install the Schleim OS browser extension locally in compatible Chromium-based browsers.

## 1. Download the ZIP file from GitHub

1. Open the [Schleim OS GitHub repository](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck).
2. Click the green **Code** button near the top.
3. Select **Download ZIP**.
4. Save the ZIP archive to your device.
5. Extract the ZIP archive completely.
6. Find the extension folder that contains the `manifest.json` file directly. This is the exact folder you must select in your browser later.

## 2. Google Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the extracted extension folder containing `manifest.json` directly.
5. Open a new tab. Schleim OS should now start. 🎉

## 3. Microsoft Edge and Brave

- **Microsoft Edge:** Open `edge://extensions`.
- **Brave:** Open `brave://extensions`.
- Enable Developer mode, choose **Load unpacked**, and then select the extracted extension folder containing the `manifest.json` file directly.

> ⚠️ **Important:** The **Load unpacked** function accepts a folder, not a ZIP file. For local installation through the browser's developer mode, you must first extract the GitHub ZIP archive. Then select the folder that contains `manifest.json` directly.

## 4. After installation

Open a new browser tab. If Schleim OS does not appear, check the browser's extension manager and follow the [troubleshooting guide](TROUBLESHOOTING.md).
