# Schleim OS 3.16.0 – Android browser release

Schleim OS is now available as an Android app in addition to the browser Extension.

## What's new

- New native Android app **Schleim Browser**, based on Mozilla GeckoView.
- The original Schleim OS Extension is bundled inside the Android app.
- Native browser toolbar with address/search, navigation, home and tabs.
- Browser menu with downloads, XPI extensions, desktop mode and Android settings.
- Android file picker and save-file dialogs.
- Android Studio project distributed as a separate ZIP, with neutral placeholders inside the Android-App template folder.
- New installation guides and documentation in German, English and Dutch.

## Release downloads

- Schleim-OS-Extension.zip: regular browser Extension.
- Schleim-Browser-Android-0.1.0-alpha22.apk: Android browser.
- Browser-OS-Extension-Template.zip: neutral browser Extension template.
- Schleim-Browser-Android-Studio-Template.zip: neutral Android Studio project.
- Schleim-OS-SHA256SUMS.txt: SHA-256 checksums for release files.

## Compatibility and notes

- Android 8.0 or newer, 64-bit ARM (arm64-v8a).
- Camera and microphone capture are disabled in the Android app.
- The Android app is currently built as a debug APK. An update may therefore require uninstalling the previous version.
- The Android app and browser Extension are updated separately.
