# 🛠️ Schleim OS – Troubleshooting

This guide helps solve common installation, sign-in and usage problems in Schleim OS 3.12.0.

| Problem | Possible solution |
|---|---|
| **The ZIP-import button is missing.** | Check whether your browser supports direct ZIP-extension import. The button may be labelled **“From .zip/.crx/.user.js”**. |
| **The ZIP file does not appear.** | Download the complete repository from GitHub using **Code → Download ZIP**. Then check your Downloads folder. |
| **Installation reports an error.** | Select the complete repository ZIP. Do not extract it first or modify it. |
| **Schleim OS does not appear in a new tab.** | Check the extension manager to make sure Schleim OS is installed and enabled. Then open a new tab. |
| **Changes are not displayed.** | Open the extension manager and reload Schleim OS. Then open a new tab. |
| **The Schleim-Store is locked.** | The Store requires a Schleim account. Select **Connect with GitHub**, install the **Schleim OS Account** app, then continue with the device code. |
| **GitHub does not detect the app installation.** | Make sure you installed the GitHub App for the same account you are using to sign in. Schleim OS checks again after device authorization. If needed, reopen the installation link and start sign-in again. |
| **The device code is not copied.** | The code remains visible. Use **Copy code** or select and copy it manually. Then open the GitHub device authorization link. |
| **Cloud backup is missing.** | Open **Settings → Schleim account**. Backup is available there only, not in the Schleim-Store. |
| **Settings are missing after switching browsers.** | Open **Settings → Schleim account**, sign in with the same GitHub account and choose **Restore cloud backup**. |
| **External content is missing or remains blank.** | Check your internet connection. Some providers block their pages from being embedded on other websites. |
| **Installation does not work in Chrome for Android.** | Chrome for Android does not support regular Chrome extensions. Use an Android browser that supports extensions and direct ZIP import. |

## Need more help?

If the problem continues, report it through [GitHub Issues](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/issues). Describe your browser, version, the steps you took and the error message. Do not share passwords or confidential login details.
