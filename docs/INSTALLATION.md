# 📥 Schleim OS – Installationsanleitung / Installation guide / Installatiehandleiding

Diese Anleitung ist auf Deutsch, Englisch und Niederländisch verfügbar.

---

## 🇩🇪 Deutsch

### 1. ZIP-Datei von GitHub herunterladen

1. Öffne das [Schleim-OS-GitHub-Repository](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck).
2. Klicke oben auf die grüne Schaltfläche **Code**.
3. Wähle **Download ZIP**.
4. Speichere das ZIP-Archiv auf deinem Gerät und entpacke es vollständig.
5. Suche den Erweiterungsordner, in dem `manifest.json` direkt liegt. Genau diesen Ordner musst du im Browser auswählen.

### 2. Google Chrome

1. Öffne `chrome://extensions`.
2. Aktiviere oben rechts den **Entwicklermodus**.
3. Klicke auf **Entpackte Erweiterung laden**.
4. Wähle den entpackten Erweiterungsordner mit der direkt darin liegenden Datei `manifest.json`.
5. Öffne einen neuen Tab. Schleim OS sollte jetzt starten. 🎉

### 3. Microsoft Edge und Brave

- **Microsoft Edge:** Öffne `edge://extensions`.
- **Brave:** Öffne `brave://extensions`.
- Aktiviere den Entwicklermodus, wähle **Entpackt laden** und danach den entpackten Erweiterungsordner mit `manifest.json`.

> ⚠️ **Wichtig:** Die Funktion **„Entpackte Erweiterung laden“** nimmt einen Ordner entgegen, keine ZIP-Datei. Für die lokale Installation über den Browser-Entwicklermodus muss das GitHub-ZIP daher zuerst entpackt werden. Wähle danach den Ordner aus, in dem `manifest.json` direkt liegt.

### 4. ZIP-Datei für den Chrome Web Store

Wenn du die Erweiterung im Chrome Web Store veröffentlichen möchtest, lädst du ein ZIP-Paket im **Chrome Web Store Developer Dashboard** hoch. Das ist nicht dasselbe wie die lokale Installation über `chrome://extensions`. Das Store-ZIP muss die Erweiterungsdateien mit `manifest.json` direkt im Hauptverzeichnis des ZIP-Archivs enthalten. Das ZIP des gesamten GitHub-Repositories ist dafür nicht automatisch geeignet.

## 🇬🇧 English

### 1. Download the ZIP file from GitHub

1. Open the [Schleim OS GitHub repository](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck).
2. Click the green **Code** button near the top.
3. Select **Download ZIP**.
4. Save the ZIP archive to your device and extract it completely.
5. Find the extension folder that contains `manifest.json` directly. This is the exact folder you must select in your browser.

### 2. Google Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the extracted extension folder containing the `manifest.json` file directly.
5. Open a new tab. Schleim OS should now start. 🎉

### 3. Microsoft Edge and Brave

- **Microsoft Edge:** Open `edge://extensions`.
- **Brave:** Open `brave://extensions`.
- Enable Developer mode, choose **Load unpacked**, and then select the extracted extension folder containing `manifest.json`.

> ⚠️ **Important:** The **Load unpacked** function accepts a folder, not a ZIP file. For local installation through the browser's developer mode, you must first extract the GitHub ZIP archive. Then select the folder that contains `manifest.json` directly.

### 4. ZIP file for the Chrome Web Store

To publish the extension in the Chrome Web Store, upload a ZIP package through the **Chrome Web Store Developer Dashboard**. This is different from installing it locally through `chrome://extensions`. The store ZIP must contain the extension files with `manifest.json` directly at the archive root. The ZIP of the entire GitHub repository is not automatically suitable for this.

## 🇳🇱 Nederlands

### 1. Het ZIP-bestand downloaden via GitHub

1. Open de [Schleim OS GitHub-repository](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck).
2. Klik bovenaan op de groene knop **Code**.
3. Kies **Download ZIP**.
4. Sla het ZIP-archief op je apparaat op en pak het volledig uit.
5. Zoek de extensiemap waarin `manifest.json` rechtstreeks staat. Dit is de map die je in de browser moet selecteren.

### 2. Google Chrome

1. Open `chrome://extensions`.
2. Schakel rechtsboven **Ontwikkelaarsmodus** in.
3. Klik op **Uitgepakte extensie laden**.
4. Selecteer de uitgepakte extensiemap waarin het bestand `manifest.json` rechtstreeks staat.
5. Open een nieuw tabblad. Schleim OS zou nu moeten starten. 🎉

### 3. Microsoft Edge en Brave

- **Microsoft Edge:** Open `edge://extensions`.
- **Brave:** Open `brave://extensions`.
- Schakel de ontwikkelaarsmodus in, kies **Uitgepakte extensie laden** en selecteer daarna de uitgepakte extensiemap met `manifest.json`.

> ⚠️ **Belangrijk:** De functie **Uitgepakte extensie laden** accepteert een map, geen ZIP-bestand. Voor een lokale installatie via de ontwikkelaarsmodus van de browser moet je het GitHub-ZIP-archief eerst uitpakken. Selecteer daarna de map waarin `manifest.json` rechtstreeks staat.

### 4. ZIP-bestand voor de Chrome Web Store

Om de extensie in de Chrome Web Store te publiceren, upload je een ZIP-pakket via het **Chrome Web Store Developer Dashboard**. Dit is iets anders dan de lokale installatie via `chrome://extensions`. Het Store-ZIP-bestand moet de extensiebestanden bevatten met `manifest.json` rechtstreeks in de hoofdmap van het archief. De ZIP van de volledige GitHub-repository is hiervoor niet automatisch geschikt.
