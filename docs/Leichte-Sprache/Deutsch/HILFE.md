# Hilfe und Fehlerbehebung – Leichte Sprache

## Die ZIP-Schaltfläche fehlt

Nicht jeder Browser kann ZIP-Dateien als Erweiterung importieren.
Prüfe, ob dein Browser diese Funktion hat.

## Die ZIP-Datei wird nicht angezeigt

Lade das ganze Projekt noch einmal von GitHub herunter.
Wähle **Code → Download ZIP**.
Prüfe danach den Download-Ordner auf deinem Gerät.

## Bei der Installation erscheint ein Fehler

Wähle die vollständige ZIP-Datei des Projekts.
Wähle keine einzelne Datei aus.
Verändere die ZIP-Datei nicht.

## Schleim OS erscheint nicht

Öffne die Erweiterungsverwaltung.
Prüfe, ob Schleim OS installiert und eingeschaltet ist.
Öffne danach einen neuen Tab.

## Eine andere Erweiterung öffnet einen neuen Tab

Vielleicht verändert eine andere Erweiterung auch den neuen Tab.
Schalte diese Erweiterung testweise aus.

## Webseiten oder Inhalte bleiben leer

Prüfe deine Internet-Verbindung.
Manche Webseiten erlauben nicht, dass sie in Schleim OS angezeigt werden.

## Einstellungen fehlen

Die Einstellungen werden im Browser-Profil gespeichert.
Bei einem anderen Browser können die Einstellungen fehlen.
Nutze die JSON-Sicherung, wenn du sie vorher erstellt hast.

## Du brauchst weitere Hilfe?

Du kannst einen Fehler auf [GitHub melden](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/issues).

Schreibe dazu:
- Welchen Browser du nutzt.
- Welche Version der Browser hat.
- Was du gemacht hast.
- Welche Fehlermeldung erscheint.

Sende niemals dein Passwort oder geheime Zugangsdaten.
