# Schleim OS installieren – Leichte Sprache

## Vor dem Start

Du brauchst einen Chromium-Browser.
Der Browser muss Erweiterungen unterstützen.
Der Browser muss auch ZIP-Dateien direkt importieren können.

Nicht jeder Browser kann das.

## Schritt 1: ZIP-Datei herunterladen

1. Öffne das [GitHub-Projekt von Schleim OS](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck).
2. Klicke auf **Code**.
3. Klicke auf **Download ZIP**.
4. Speichere die Datei auf deinem Gerät.

Du lädst damit das ganze Projekt herunter.

## Schritt 2: ZIP-Datei importieren

1. Öffne die Erweiterungsverwaltung im Browser.
2. Schalte den Entwicklermodus ein, wenn der Browser das verlangt.
3. Suche die Funktion zum Importieren einer ZIP-Datei.
4. Sie kann zum Beispiel **From .zip/.crx/.user.js** heißen.
5. Wähle die ZIP-Datei aus, die du gerade heruntergeladen hast.
6. Bestätige den Import.

**Wichtig:** Entpacke die ZIP-Datei nicht vorher.

Der Browser muss die Erweiterung im Ordner `extension` selbst finden können.

## Schritt 3: Schleim OS öffnen

Öffne einen neuen Tab im Browser.

Wenn Schleim OS nicht erscheint, prüfe, ob die Erweiterung eingeschaltet ist.

## Noch wichtig

Die Schaltfläche kann in jedem Browser anders heißen.
Der ZIP-Import funktioniert nur in Browsern, die diese Funktion anbieten.

## Den Schleim-Store benutzen

Für den Schleim-Store brauchst du ein Schleim-Konto.
Öffne den Store und tippe auf **Mit GitHub verbinden**.
Installiere zuerst die GitHub-App **Schleim OS Account**.
Kehre danach zu Schleim OS zurück und tippe auf **Ich habe die App installiert – weiter**.
Folge den Schritten mit dem Gerätecode.
