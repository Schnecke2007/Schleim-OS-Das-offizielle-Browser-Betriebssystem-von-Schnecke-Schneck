# Schleim-Konto und Cloud-Sicherung – Leichte Sprache

## Was ist ein Schleim-Konto?

Du meldest dich mit deinem GitHub-Konto an.

Schleim OS fragt dich nicht nach deinem GitHub-Passwort.

Schleim OS speichert dein GitHub-Passwort nicht.

## So meldest du dich an

1. Öffne **Einstellungen → Schleim-Konto** oder den Schleim-Store.
2. Tippe auf **Mit GitHub verbinden**.
3. GitHub öffnet die Seite der App **Schleim OS Account**.
4. Installiere die App in deinem GitHub-Konto.
5. Gehe zurück zu Schleim OS.
6. Tippe auf **Ich habe die App installiert – weiter**.
7. Schleim OS zeigt einen Code.
8. Nach kurzer Zeit versucht Schleim OS, den Code zu kopieren.
9. Danach öffnet sich die GitHub-Seite für den Code.
10. Gib den Code bei GitHub ein.
11. Bestätige die App **Schleim OS Account**.

Du kannst den Code auch selbst kopieren.

Nach der Anmeldung prüft Schleim OS, ob die App in deinem GitHub-Konto installiert ist. Diese Prüfung kann einige Minuten dauern.

## Wo ist die Cloud-Sicherung?

Die Cloud-Sicherung ist nur hier:

**Einstellungen → Schleim-Konto**

Im Schleim-Store gibt es keine Sicherung.

So speicherst du eine Sicherung:

1. Melde dich mit deinem Schleim-Konto an.
2. Öffne **Einstellungen → Schleim-Konto**.
3. Tippe auf **Jetzt in der Cloud sichern**.

Die Sicherung wird in einem privaten GitHub-Repository gespeichert.

## Was wird gespeichert?

Die Sicherung enthält:

- Deine Schleim-OS-Einstellungen.
- Die Reihenfolge der Apps auf dem Startbildschirm.
- Deine installierten Store-Apps.
- Dein Hintergrundbild.
- Deine eigene Hintergrundbild-Datei oder deren Internet-Adresse.

Die Sicherung wird nicht von selbst erstellt.

Du musst sie selbst starten.

## Sicherung wiederherstellen

1. Öffne **Einstellungen → Schleim-Konto**.
2. Melde dich mit demselben GitHub-Konto an.
3. Tippe auf **Cloud-Sicherung wiederherstellen**.
4. Bestätige die Wiederherstellung.

**Achtung:** Die Sicherung ersetzt die Einstellungen auf diesem Gerät.

## Sicherheit

Das GitHub-Repository mit der Sicherung muss privat sein.

Dein GitHub-Passwort und dein Zugriffstoken stehen nicht in der Sicherungsdatei.

Melde dich nur auf der echten GitHub-Webseite an.
