# Schleim OS – Leichte Sprache

## Was ist Schleim OS?

Schleim OS ist eine Erweiterung für einen Internet-Browser.

Eine Erweiterung ist ein Zusatz-Programm für den Browser.

Schleim OS verändert die Seite, die sich bei einem neuen Tab öffnet. Du siehst dann einen eigenen Start-Bildschirm.

Dort gibt es Kacheln für Apps und Webseiten.

**Wichtig:** Schleim OS ist kein eigenes Betriebssystem. Es ersetzt nicht Windows, Android oder Linux.

## Was kann Schleim OS?

- Du kannst Apps und Webseiten über Kacheln öffnen.
- Du kannst die Kacheln verschieben.
- Du kannst das Aussehen ändern.
- Du kannst eine Farbe und einen Hintergrund auswählen.
- Du kannst deine Einstellungen unter **Einstellungen → Schleim-Konto** manuell in der Cloud sichern.
- Die Sicherung wird nicht automatisch erstellt.
- Der Schleim-Store zeigt Apps und Webseiten. Für den Store brauchst du ein Schleim-Konto.
- Die Oberfläche gibt es auf Deutsch, Englisch und Niederländisch.

## Die Erweiterung installieren

Lade zuerst die vollständige ZIP-Datei von GitHub herunter. Entpacke die Datei nicht. Danach importierst du die ZIP-Datei in einem Browser, der diesen Import unterstützt.

Die genaue Anleitung steht hier: [Installation in Leichter Sprache](INSTALLATION.md).

## Der Schleim-Store

Der Schleim-Store ist nur nach einer Anmeldung verfügbar. Du kannst dort Apps suchen, installieren und bewerten.

Im Store gibt es keine Cloud-Sicherung. Die Sicherung ist nur in den Einstellungen.
