# Schleim OS 3.19.0 – Neue Funktionen

Schleim Browser bekommt drei neue Funktionen.

## Das ist neu

- **Verlauf:** Im Menü gibt es jetzt den Punkt **Verlauf**. Dort siehst du besuchte Internetseiten. Du kannst eine Seite wieder öffnen. Du kannst den Verlauf auch löschen.
- **Sicheres DNS:** Der Browser nutzt einen festen DNS-Server. Die Verbindung ist verschlüsselt. Du kannst den DNS-Server nicht ändern. In den Einstellungen steht nur, dass eine sichere DNS-Verbindung genutzt wird.
- **Tabs speichern:** Der Browser speichert deine letzten vier Tabs. Er speichert auch, welcher Tab gerade offen war. Beim nächsten Start öffnet er die Tabs wieder.

## Wichtig

- Verlauf und Tabs werden auf deinem Gerät gespeichert.
- Wenn du die App deinstallierst, können diese Daten verloren gehen.
- Bei einem neuen Update musst du die alte App vielleicht zuerst deinstallieren.
- Danach kannst du die neue APK installieren.
- GeckoView nutzt für einige interne Netzwerk-Aufgaben eigene Wege. Der sichere DNS-Dienst wird für normale Internetseiten genutzt.

## Version

- Schleim OS Extension: **3.19.0**
- Schleim Browser: **0.1.0-alpha29**
