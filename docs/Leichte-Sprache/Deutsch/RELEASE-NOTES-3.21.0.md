# Schleim OS 3.21.0 – Neue Erweiterungs-Details

## Schleim Browser für Android

- **Details:** Jede Erweiterung hat jetzt einen eigenen Button **Details**.
- **Informationen:** Dort siehst du die Daten, die der Browser für diese Erweiterung kennt. Zum Beispiel Name, Version, Beschreibung und Berechtigungen.
- **Einstellungen:** Hat eine Erweiterung eine eigene Einstellungsseite, kannst du diese öffnen. Hat sie keine Seite, zeigt der Browser einen Hinweis.
- **Berechtigungen:** Optionale Berechtigungen kannst du einzeln erlauben oder wieder entziehen.
- **Private Fenster:** Bei passenden Erweiterungen kannst du **In privaten Fenstern ausführen** einschalten. Die Erweiterung darf private Fenster laut Manifest nicht verbieten.
- **VPN:** Die Einstellung macht allein noch kein VPN. Eine VPN-Erweiterung muss private Fenster selbst unterstützen. Der Browser startet dadurch keinen systemweiten VPN-Tunnel.
- **Sicherung:** Die Einstellung für private Fenster wird mit dem verschlüsselten Browser-Profil gespeichert. Sie kann auf einem anderen Gerät wiederhergestellt werden.

## Was bleibt gleich?

Das braune Design **#251205**, Tabs, Verlauf, Lesezeichen, Passwort-Manager, Gastmodus und NextDNS bleiben erhalten. Die DNS-Einstellung wird nicht geändert.

## Wichtige Hinweise

Nicht jede Erweiterung hat eine eigene Einstellungsseite. Nicht jede Erweiterung funktioniert mit GeckoView. Der Browser zeigt nur Daten an, die er wirklich von der Erweiterung bekommt.
