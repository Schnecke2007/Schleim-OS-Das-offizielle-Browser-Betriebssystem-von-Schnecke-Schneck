# Der Schleim-Store – Leichte Sprache

## Was ist der Schleim-Store?

Im Schleim-Store findest du Webseiten und Web-Apps.

Du kannst eine App auf deinem Start-Bildschirm installieren.

Die App öffnet sich dann in einem neuen Browser-Tab.

## Anmeldung ist nötig

Du brauchst ein **Schleim-Konto**.

Ohne Anmeldung ist der Schleim-Store gesperrt.

So meldest du dich an:

1. Öffne den Schleim-Store.
2. Tippe auf **Mit GitHub verbinden**.
3. GitHub öffnet die Seite der App **Schleim OS Account**.
4. Installiere die App in deinem GitHub-Konto.
5. Gehe zurück zu Schleim OS.
6. Tippe auf **Ich habe die App installiert – weiter**.
7. Schleim OS zeigt einen Code.
8. Der Code wird nach kurzer Zeit kopiert.
9. Die GitHub-Seite zum Eingeben des Codes öffnet sich.
10. Gib den Code bei GitHub ein und bestätige die App.

Du kannst den Code auch selbst kopieren.

Nach der Anmeldung prüft Schleim OS, ob die GitHub-App installiert ist.

## Apps im Store benutzen

- **Suchen:** Suche nach einer App oder Webseite.
- **Ansehen:** Lies den Namen und die Beschreibung.
- **Installieren:** Tippe auf **Installieren**.
- **Öffnen:** Tippe auf **Öffnen**.
- **Entfernen:** Tippe auf **Deinstallieren**.

Du kannst auch eine Webseite vorschlagen.

Der Vorschlag wird auf GitHub geprüft. Er erscheint nicht sofort im Store.

## Bewertungen

Du kannst eine App mit Sternen bewerten.

Dazu öffnet sich ein Formular auf GitHub.

Dein GitHub-Name und deine Bewertung sind öffentlich sichtbar.

Schreibe dort keine privaten Daten.

## Was passiert beim Abmelden?

Der Schleim-Store wird wieder gesperrt.

Installierte Store-Apps werden vorübergehend nicht auf dem Start-Bildschirm gezeigt.

Nach der nächsten Anmeldung erscheinen sie wieder.

## Wichtig

Die Anmeldung schützt den Store in Schleim OS.

Die Store-Dateien auf GitHub sind trotzdem öffentlich.
