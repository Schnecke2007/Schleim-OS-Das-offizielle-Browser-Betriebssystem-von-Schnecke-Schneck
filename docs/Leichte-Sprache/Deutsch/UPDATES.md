# Schleim OS aktualisieren – Leichte Sprache

## Neue Version herunterladen

1. Öffne die **Einstellungen** in Schleim OS.
2. Wähle **Schleim OS aktualisieren**.
3. Tippe auf **Nach Updates suchen**.
4. Gibt es eine neue Version? Tippe auf **Original-Extension-ZIP herunterladen**.
5. Schleim OS lädt die Datei aus dem neuesten GitHub-Release herunter. Du musst GitHub nicht selbst öffnen.

Du kannst die [Extension auch direkt bei GitHub herunterladen](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/releases/latest/download/Schleim-OS-Extension.zip).

## Update installieren

1. **Entpacke die ZIP-Datei nicht.**
2. Öffne die Erweiterungsverwaltung in einem Browser mit ZIP-Import.
3. Schalte bei Bedarf den Entwicklermodus ein.
4. Tippe auf **+ (from .zip/.crx/.user.js)**.
5. Wähle die heruntergeladene Datei **Schleim-OS-Extension.zip**.
6. Bestätige den Import oder das Update im Browser.

Der Download startet über Schleim OS. Die Installation musst du danach selbst im Browser bestätigen.

## Wichtig

Nicht jeder Browser kann ZIP-Dateien importieren. Normales Chrome für Android unterstützt keine Erweiterungen. Desktop-Chrome kann ZIP-Dateien nicht direkt importieren.

Du brauchst einen Browser mit einer Import-Funktion für ZIP-Erweiterungen. Die ZIP-Datei bleibt dabei unverändert.
