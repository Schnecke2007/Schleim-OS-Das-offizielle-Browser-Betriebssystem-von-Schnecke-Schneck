# Schleim account and cloud backup – Plain Language

## What is a Schleim account?

You sign in with your GitHub account.

Schleim OS does not ask for your GitHub password.

Schleim OS does not store your GitHub password.

## How to sign in

1. Open **Settings → Schleim account** or the Schleim-Store.
2. Select **Connect with GitHub**.
3. GitHub opens the page for the **Schleim OS Account** app.
4. Install the app in your GitHub account.
5. Return to Schleim OS.
6. Select **I installed the app – continue**.
7. Schleim OS shows a code.
8. After a short delay, Schleim OS tries to copy the code.
9. The GitHub page for the code opens.
10. Enter the code on GitHub.
11. Approve the **Schleim OS Account** app.

You can also copy the code yourself.

After sign-in, Schleim OS checks whether the app is installed in your GitHub account. This check may take a few minutes.

## Where is cloud backup?

Cloud backup is available only here:

**Settings → Schleim account**

There is no backup button in the Schleim-Store.

To save a backup:

1. Sign in with your Schleim account.
2. Open **Settings → Schleim account**.
3. Select **Back up to cloud now**.

The backup is saved in a private GitHub repository.

## What is saved?

The backup includes:

- Your Schleim OS settings.
- The order of apps on the home screen.
- Your installed Store apps.
- Your wallpaper.
- Your own wallpaper image or its web address.

The backup is not created automatically.

You must start it yourself.

## Restore a backup

1. Open **Settings → Schleim account**.
2. Sign in with the same GitHub account.
3. Select **Restore cloud backup**.
4. Confirm the restore.

**Warning:** The backup replaces the settings on this device.

## Safety

The GitHub repository for the backup must be private.

Your GitHub password and access token are not inside the backup file.

Only sign in on the real GitHub website.
