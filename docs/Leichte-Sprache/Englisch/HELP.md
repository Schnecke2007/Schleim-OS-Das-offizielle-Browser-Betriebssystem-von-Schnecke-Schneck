# Help and troubleshooting – Plain Language

## The ZIP button is missing

Not every browser can import ZIP files as extensions.
Check whether your browser supports this feature.

## The ZIP file is not shown

Download the complete project again from GitHub.
Choose **Code → Download ZIP**.
Then check your device's Downloads folder.

## Installation shows an error

Choose the complete project ZIP file.
Do not choose one file from the project.
Do not change the ZIP file.

## Schleim OS does not appear

Open the extension manager.
Check that Schleim OS is installed and enabled.
Then open a new tab.

## Another extension opens the new tab

Another extension may also change the new-tab page.
Try turning that extension off.

## Websites or content are blank

Check your internet connection.
Some websites do not allow their pages to be shown inside Schleim OS.

## Your settings are missing

Settings are saved in the browser profile.
Settings may not appear in another browser.
Use your JSON backup if you made one.

## Need more help?

[Report a problem on GitHub](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/issues).

Tell us:
- Which browser you use.
- Which browser version you use.
- What you did.
- Which error message you saw.

Never send your password or private login details.
