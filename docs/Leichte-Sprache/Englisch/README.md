# Schleim OS – Plain Language

## What is Schleim OS?

Schleim OS is an extension for an internet browser.
An extension is an extra program for a browser.

Schleim OS changes the page that opens in a new tab.
You see a personal start page with tiles for apps and websites.

**Important:** Schleim OS is not a complete operating system. It does not replace Windows, Android or Linux.

## What can it do?

- Open apps and websites from tiles.
- Move the tiles.
- Change the design, colour and background.
- Save your settings manually under **Settings → Schleim account**.
- The backup is not created automatically.
- The Schleim-Store shows apps and websites. You need a Schleim account to use the Store.
- Use the interface in German, English or Dutch.

## Install the extension

Download the complete ZIP file from GitHub. Do not extract it. Import the ZIP file in a browser that supports direct ZIP import.

Read the [plain-language installation guide](INSTALLATION.md).

## The Schleim-Store

The Schleim-Store is only available after sign-in. You can search for apps, install them and rate them.

There is no cloud backup in the Store. Backup is available only in Settings.
