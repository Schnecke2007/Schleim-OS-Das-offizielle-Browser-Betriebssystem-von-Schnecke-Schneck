# Schleim OS 3.19.0 – New features

Schleim Browser has three new features.

## What is new

- **History:** The menu now has a **History** item. It shows websites you visited. You can open a page again. You can also clear the history.
- **Secure DNS:** The browser uses one fixed DNS server. The connection is encrypted. You cannot change the DNS server. Settings only say that a secure DNS connection is used.
- **Save tabs:** The browser saves your last four tabs. It also saves which tab was open. The tabs open again when you start the app.

## Important

- History and tabs are saved on your device.
- Uninstalling the app can delete this data.
- A new update may require you to uninstall the old app first.
- Then you can install the new APK.
- GeckoView uses special network lookups for some system tasks. Secure DNS is used for normal website lookups.

## Version

- Schleim OS Extension: **3.19.0**
- Schleim Browser: **0.1.0-alpha29**
