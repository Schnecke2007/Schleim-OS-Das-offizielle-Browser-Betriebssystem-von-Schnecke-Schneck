# Schleim OS 3.20.0 – New browser features

## Schleim Browser for Android

- **Welcome screen:** The app shows a short guide when you start it for the first time. You can go forward or back. You can also skip the guide.
- **Guest Mode:** Guest Mode uses private browser sessions. Your visited pages and forms are not saved in the normal browser profile. Tabs, bookmarks and passwords are not saved either. There is no cloud backup. Your normal profile stays separate.
- **Bookmarks:** You can save websites. You can open them later, change them or delete them.
- **Password manager:** New passwords are saved only after you agree. Passwords are encrypted. You need your Android device's secure screen lock to open the manager.
- **Schleim account:** The account is now in Settings. You cannot use cloud backup or restore until you sign in.
- **GitHub sign-in:** First, the GitHub App page opens in a new tab. Install the app named **Schleim OS Account** there. Then you can close the tab. Return to Settings → Schleim account and select Continue. The device code is shown and copied. GitHub's approval page opens in another tab.
- **Private cloud:** The browser profile is saved in encrypted form. The app uses a private GitHub repository for this. You need the same GitHub account and your backup password to restore the profile on another device.
- **Sync:** The backup includes settings, history, saved tabs, bookmarks, passwords and add-on information. Available XPI files can be saved and installed again.

## Important notes

Website cookies, active website sign-ins, form entries and private data from individual add-ons are not transferred. Normal downloads are not synced. Add-ons can be installed automatically only when the matching XPI file is in the backup.

The dark brown design stays the same. The current secure DNS connection is not changed.
