# The Schleim-Store – Plain Language

## What is the Schleim-Store?

The Schleim-Store contains websites and web apps.

You can install an app on your home screen.

The app opens in a new browser tab.

## You must sign in

You need a **Schleim account**.

The Schleim-Store is locked when you are signed out.

Follow these steps:

1. Open the Schleim-Store.
2. Select **Connect with GitHub**.
3. GitHub opens the page for the **Schleim OS Account** app.
4. Install the app in your GitHub account.
5. Return to Schleim OS.
6. Select **I installed the app – continue**.
7. Schleim OS shows a code.
8. After a short delay, Schleim OS copies the code.
9. The GitHub page for entering the code opens.
10. Enter the code on GitHub and approve the app.

You can also copy the code yourself.

After sign-in, Schleim OS checks whether the GitHub App is installed.

## Use apps in the Store

- **Search:** Search for an app or website.
- **Read:** Check the name and description.
- **Install:** Select **Install**.
- **Open:** Select **Open**.
- **Remove:** Select **Uninstall**.

You can also suggest a website.

The suggestion is checked on GitHub. It does not appear in the Store right away.

## Ratings

You can rate an app with stars.

A form opens on GitHub.

Your GitHub name and rating are public.

Do not write private information in the form.

## What happens when you sign out?

The Schleim-Store is locked again.

Installed Store apps are temporarily hidden from the home screen.

They appear again after you sign in.

## Cloud backup

There is no cloud backup in the Schleim-Store.

You can find it only here:

**Settings → Schleim account**

You must start the backup yourself.

It also saves your app order, installed Store apps and wallpaper.

The backup is not created automatically.

[Schleim account and cloud backup in plain language](ACCOUNT-CLOUD.md)

## Important

Sign-in protects the Store inside Schleim OS.

The Store files on GitHub are still public.
