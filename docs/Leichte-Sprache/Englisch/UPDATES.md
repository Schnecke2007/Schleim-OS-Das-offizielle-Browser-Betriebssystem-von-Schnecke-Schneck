# Update Schleim OS – Plain Language

## Download a new version

1. Open **Settings** in Schleim OS.
2. Select **Update Schleim OS**.
3. Select **Check for updates**.
4. Is there a new version? Select **Download original Extension ZIP**.
5. Schleim OS downloads the file from the latest GitHub release. You do not need to open GitHub yourself.

You can also [download the Extension directly from GitHub](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/releases/latest/download/Schleim-OS-Extension.zip).

## Install the update

1. **Do not extract the ZIP file.**
2. Open the extension manager in a browser with ZIP import.
3. Turn on Developer mode if needed.
4. Tap **+ (from .zip/.crx/.user.js)**.
5. Choose the downloaded **Schleim-OS-Extension.zip** file.
6. Confirm the import or update in your browser.

Schleim OS starts the download. You must confirm the installation yourself in the browser.

## Important

Not every browser can import ZIP files. Standard Chrome for Android does not support extensions. Desktop Chrome cannot import ZIP files directly.

You need a browser with an import option for ZIP extensions. Keep the ZIP file unchanged.

## Update the Android app

The Android app has its own update check.

1. Open the browser menu.
2. Open **Settings**.
3. Tap **Check for updates**.
4. Download the new APK first.
5. Return to the update window.
6. Choose **Uninstall old app**.
7. Confirm the Android prompt.
8. Install the downloaded APK.

Important: Removing the old app can delete history and saved tabs. Back up important data first.

[Android updates in plain language](ANDROID-BROWSER.md)


If you are signed in, create a backup before uninstalling. Open **Settings → Schleim account**. After installing the new app, you can restore it there. You need your GitHub account and backup password. Without an account backup, local data can be lost.
