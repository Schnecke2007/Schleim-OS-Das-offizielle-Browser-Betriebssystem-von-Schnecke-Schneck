# Schleim-account en cloudback-up – Eenvoudige taal

## Wat is een Schleim-account?

Je meldt je aan met je GitHub-account.

Schleim OS vraagt niet om je GitHub-wachtwoord.

Schleim OS slaat je GitHub-wachtwoord niet op.

## Zo meld je je aan

1. Open **Instellingen → Schleim-account** of de Schleim-Store.
2. Kies **Verbinden met GitHub**.
3. GitHub opent de pagina van de app **Schleim OS Account**.
4. Installeer de app in je GitHub-account.
5. Ga terug naar Schleim OS.
6. Kies **Ik heb de app geïnstalleerd – verder**.
7. Schleim OS toont een code.
8. Na korte tijd probeert Schleim OS de code te kopiëren.
9. De GitHub-pagina voor de code wordt daarna geopend.
10. Voer de code in op GitHub.
11. Geef toestemming voor de app **Schleim OS Account**.

Je kunt de code ook zelf kopiëren.

Na het aanmelden controleert Schleim OS of de app in je GitHub-account is geïnstalleerd. Deze controle kan enkele minuten duren.

## Waar vind je de cloudback-up?

De cloudback-up is alleen hier beschikbaar:

**Instellingen → Schleim-account**

In de Schleim-Store staat geen back-upknop.

Zo sla je een back-up op:

1. Meld je aan met je Schleim-account.
2. Open **Instellingen → Schleim-account**.
3. Kies **Nu opslaan in de cloud**.

De back-up wordt opgeslagen in een privérepository op GitHub.

## Wat wordt opgeslagen?

De back-up bevat:

- Je Schleim OS-instellingen.
- De volgorde van de apps op het startscherm.
- Je geïnstalleerde Store-apps.
- Je achtergrond.
- Je eigen achtergrondafbeelding of het webadres ervan.

De back-up wordt niet automatisch gemaakt.

Je moet deze zelf starten.

## Een back-up herstellen

1. Open **Instellingen → Schleim-account**.
2. Meld je aan met hetzelfde GitHub-account.
3. Kies **Cloudback-up herstellen**.
4. Bevestig het herstellen.

**Let op:** De back-up vervangt de instellingen op dit apparaat.

## Veiligheid

De GitHub-repository voor de back-up moet privé zijn.

Je GitHub-wachtwoord en toegangstoken staan niet in het back-upbestand.

Meld je alleen aan op de echte GitHub-website.
