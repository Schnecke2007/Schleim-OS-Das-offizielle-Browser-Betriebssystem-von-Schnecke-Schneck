# Schleim OS – Eenvoudige taal

## Wat is Schleim OS?

Schleim OS is een uitbreiding voor een internetbrowser.
Een uitbreiding is een extra programma voor de browser.

Schleim OS verandert de pagina die opent wanneer je een nieuw tabblad opent.
Je ziet dan een eigen startpagina met tegels voor apps en websites.

**Belangrijk:** Schleim OS is geen volledig besturingssysteem. Het vervangt Windows, Android of Linux niet.

## Wat kun je ermee doen?

- Apps en websites openen via tegels.
- De tegels verplaatsen.
- Het ontwerp, de kleur en de achtergrond veranderen.
- Instellingen opslaan in een JSON-bestand.
- De interface gebruiken in het Duits, Engels en Nederlands.

Pak het bestand niet uit.
Importeer het ZIP-bestand in een browser die deze import ondersteunt.
