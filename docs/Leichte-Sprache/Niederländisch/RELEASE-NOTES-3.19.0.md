# Schleim OS 3.19.0 – Nieuwe functies

Schleim Browser heeft drie nieuwe functies.

## Wat is nieuw

- **Geschiedenis:** In het menu staat nu **Geschiedenis**. Je ziet welke websites je hebt bezocht. Je kunt een pagina opnieuw openen. Je kunt de geschiedenis ook wissen.
- **Veilige DNS:** De browser gebruikt één vaste DNS-server. De verbinding is versleuteld. Je kunt de DNS-server niet veranderen. In Instellingen staat alleen dat een veilige DNS-verbinding wordt gebruikt.
- **Tabbladen opslaan:** De browser bewaart je laatste vier tabbladen. Ook wordt opgeslagen welk tabblad actief was. Bij de volgende start worden de tabbladen opnieuw geopend.

## Belangrijk

- De geschiedenis en tabbladen worden op je apparaat opgeslagen.
- Als je de app verwijdert, kunnen deze gegevens verloren gaan.
- Bij een nieuwe update moet je misschien eerst de oude app verwijderen.
- Daarna kun je de nieuwe APK installeren.
- GeckoView gebruikt voor sommige interne netwerktaken eigen opvragingen. Veilige DNS wordt gebruikt voor normale website-opvragingen.

## Versie

- Schleim OS Extension: **3.19.0**
- Schleim Browser: **0.1.0-alpha29**
