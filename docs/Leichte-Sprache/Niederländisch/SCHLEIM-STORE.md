# De Schleim-Store – Eenvoudige taal

## Wat is de Schleim-Store?

In de Schleim-Store vind je websites en webapps.

Je kunt een app op je startscherm installeren.

De app opent daarna in een nieuw browsertabblad.

## Aanmelden is verplicht

Je hebt een **Schleim-account** nodig.

Zonder aanmelding is de Schleim-Store vergrendeld.

Volg deze stappen:

1. Open de Schleim-Store.
2. Kies **Verbinden met GitHub**.
3. GitHub opent de pagina van de app **Schleim OS Account**.
4. Installeer de app in je GitHub-account.
5. Ga terug naar Schleim OS.
6. Kies **Ik heb de app geïnstalleerd – verder**.
7. Schleim OS toont een code.
8. Na korte tijd wordt de code gekopieerd.
9. De GitHub-pagina om de code in te voeren wordt geopend.
10. Voer de code in op GitHub en geef toestemming voor de app.

Je kunt de code ook zelf kopiëren.

Na de aanmelding controleert Schleim OS of de GitHub-app is geïnstalleerd.

## Apps in de Store gebruiken

- **Zoeken:** Zoek naar een app of website.
- **Bekijken:** Lees de naam en beschrijving.
- **Installeren:** Kies **Installeren**.
- **Openen:** Kies **Openen**.
- **Verwijderen:** Kies **Deïnstalleren**.

Je kunt ook een website voorstellen.

Het voorstel wordt op GitHub gecontroleerd. Het verschijnt niet meteen in de Store.

## Beoordelingen

Je kunt een app met sterren beoordelen.

Er wordt een formulier op GitHub geopend.

Je GitHub-naam en beoordeling zijn openbaar zichtbaar.

Vul geen privégegevens in.

## Wat gebeurt er als je je afmeldt?

De Schleim-Store wordt opnieuw vergrendeld.

Geïnstalleerde Store-apps worden tijdelijk verborgen op het startscherm.

Na de volgende aanmelding verschijnen ze weer.

## Belangrijk

De aanmelding beschermt de Store binnen Schleim OS.

De Store-bestanden op GitHub blijven openbaar.
