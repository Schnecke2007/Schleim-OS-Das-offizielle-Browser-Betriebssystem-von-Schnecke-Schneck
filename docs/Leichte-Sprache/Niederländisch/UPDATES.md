# Schleim OS bijwerken – Eenvoudige taal

## Na de eerste installatie

Je hoeft niet elke keer zelf op GitHub naar een nieuwe versie te zoeken.

1. Open **Instellingen** in Schleim OS.
2. Zoek **Schleim OS bijwerken**.
3. Kies **Controleren op updates**.
4. Schleim OS controleert de versie op GitHub.
5. Is er een nieuwere versie? Dan verschijnt er een downloadlink.
6. Kies **Nieuwste ZIP-versie downloaden**.

## De update installeren

De download installeert de update nog niet.

1. Open het extensiebeheer van je browser.
2. Zoek de functie om ZIP-bestanden te importeren.
3. Selecteer het ZIP-bestand dat je hebt gedownload.
4. Bevestig de update als je browser daarom vraagt.
5. Open een nieuw tabblad.

Gebruik dezelfde importfunctie als bij de eerste installatie.

Niet elke browser kan ZIP-bestanden rechtstreeks importeren.

## Waarom gaat dit niet helemaal automatisch?

De browser beschermt extensies.

Een extensie mag zichzelf niet zomaar vervangen door een ZIP-bestand.

De browser moet de update toestaan of bevestigen.

Schleim OS kan de nieuwe versie vinden en downloaden. Je browser verzorgt de installatie.

## Belangrijk

- De updatecontrole vergelijkt versienummers.
- De maker moet het versienummer bij elke nieuwe versie verhogen.
- De download bevat het openbare project.
- Je hoeft niet bij GitHub aan te melden om op updates te controleren.
