# Schleim OS bijwerken – Eenvoudige taal

## Een nieuwe versie downloaden

1. Open **Instellingen** in Schleim OS.
2. Kies **Schleim OS bijwerken**.
3. Kies **Controleren op updates**.
4. Is er een nieuwe versie? Kies dan **Oorspronkelijke Extension-ZIP downloaden**.
5. Schleim OS downloadt het bestand uit de nieuwste GitHub-release. Je hoeft GitHub niet zelf te openen.

Je kunt de [Extension ook rechtstreeks via GitHub downloaden](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/releases/latest/download/Schleim-OS-Extension.zip).

## De update installeren

1. **Pak het ZIP-bestand niet uit.**
2. Open het extensiebeheer in een browser met ZIP-import.
3. Schakel zo nodig Ontwikkelaarsmodus in.
4. Tik op **+ (from .zip/.crx/.user.js)**.
5. Selecteer het gedownloade bestand **Schleim-OS-Extension.zip**.
6. Bevestig de import of update in je browser.

Schleim OS start de download. Je moet de installatie zelf bevestigen in de browser.

## Belangrijk

Niet elke browser kan ZIP-bestanden importeren. De gewone Chrome voor Android ondersteunt geen extensies. Desktop-Chrome kan ZIP-bestanden niet rechtstreeks importeren.

Je hebt een browser nodig met een importoptie voor ZIP-extensies. Laat het ZIP-bestand ongewijzigd.
