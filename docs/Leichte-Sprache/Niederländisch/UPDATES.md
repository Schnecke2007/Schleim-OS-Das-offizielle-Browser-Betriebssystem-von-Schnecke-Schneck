# Schleim OS bijwerken – Eenvoudige taal

## Een nieuwe versie downloaden

1. Open **Instellingen** in Schleim OS.
2. Zoek **Schleim OS bijwerken**.
3. Kies **Controleren op updates**.
4. Is er een nieuwe versie? Kies dan **Nieuwste ZIP-versie downloaden**.
5. Je kunt de [extensie ook op de Releases-pagina downloaden](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/releases/latest/download/Schleim-OS-Extension.zip).

## De update installeren

1. Pak het nieuwe ZIP-bestand uit.
2. Kopieer de bestanden naar dezelfde map als de oude extensie.
3. Overschrijf de oude bestanden.
4. Open het extensiebeheer.
5. Klik bij Schleim OS op **Opnieuw laden**.
6. Open een nieuw tabblad.

Gebruik indien mogelijk dezelfde map als voorheen.

## Belangrijk

De download installeert de update niet zelf.
Je browser moet de extensie opnieuw laden.

Het versienummer moet bij elke nieuwe release worden verhoogd.
