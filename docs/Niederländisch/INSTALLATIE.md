# 📥 Schleim OS – Installatiehandleiding

Deze handleiding legt uit hoe je de Schleim OS-browserextensie lokaal installeert in compatibele Chromium-browsers.

## 1. Het ZIP-bestand downloaden via GitHub

1. Open de [Schleim OS GitHub-repository](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck).
2. Klik bovenaan op de groene knop **Code**.
3. Kies **Download ZIP**.
4. Sla het ZIP-archief op je apparaat op.
5. Pak het ZIP-archief volledig uit.
6. Zoek de extensiemap waarin het bestand `manifest.json` rechtstreeks staat. Dit is de exacte map die je later in de browser moet selecteren.

## 2. Google Chrome

1. Open `chrome://extensions`.
2. Schakel rechtsboven **Ontwikkelaarsmodus** in.
3. Klik op **Uitgepakte extensie laden**.
4. Selecteer de uitgepakte extensiemap waarin `manifest.json` rechtstreeks staat.
5. Open een nieuw tabblad. Schleim OS zou nu moeten starten. 🎉

## 3. Microsoft Edge en Brave

- **Microsoft Edge:** Open `edge://extensions`.
- **Brave:** Open `brave://extensions`.
- Schakel de ontwikkelaarsmodus in, kies **Uitgepakte extensie laden** of **Load unpacked** en selecteer daarna de uitgepakte extensiemap waarin het bestand `manifest.json` rechtstreeks staat.

> ⚠️ **Belangrijk:** De functie **Uitgepakte extensie laden** accepteert een map, geen ZIP-bestand. Voor een lokale installatie via de ontwikkelaarsmodus van de browser moet je het GitHub-ZIP-archief eerst uitpakken. Selecteer daarna de map waarin `manifest.json` rechtstreeks staat.

## 4. Na de installatie

Open een nieuw browsertabblad. Als Schleim OS niet verschijnt, controleer dan het extensiebeheer van de browser en raadpleeg de [handleiding voor probleemoplossing](PROBLEMEN-OPLOSSEN.md).
