# 🛠️ Schleim OS – Problemen oplossen

Hier vind je oplossingen voor veelvoorkomende problemen met installatie, aanmelding en gebruik van Schleim OS 3.12.0.

| Probleem | Mogelijke oplossing |
|---|---|
| **De ZIP-importknop ontbreekt.** | Controleer of je browser het rechtstreeks importeren van ZIP-extensies ondersteunt. De knop kan bijvoorbeeld **“From .zip/.crx/.user.js”** heten. |
| **Het ZIP-bestand wordt niet weergegeven.** | Download de volledige repository via GitHub met **Code → Download ZIP**. Controleer daarna je map Downloads. |
| **De installatie geeft een foutmelding.** | Selecteer de volledige repository-ZIP. Pak het bestand niet eerst uit en wijzig het niet. |
| **Schleim OS verschijnt niet in een nieuw tabblad.** | Controleer in het extensiebeheer of Schleim OS is geïnstalleerd en ingeschakeld. Open daarna een nieuw tabblad. |
| **Wijzigingen worden niet weergegeven.** | Open het extensiebeheer en laad Schleim OS opnieuw. Open daarna een nieuw tabblad. |
| **De Schleim-Store is vergrendeld.** | De Store vereist een Schleim-account. Kies **Verbinden met GitHub**, installeer de app **Schleim OS Account** en ga daarna verder met de apparaatcode. |
| **GitHub herkent de app-installatie niet.** | Controleer of je de GitHub-app hebt geïnstalleerd voor hetzelfde account waarmee je je aanmeldt. Schleim OS controleert opnieuw na de apparaatmachtiging. Open zo nodig de installatielink opnieuw en start de aanmelding opnieuw. |
| **De apparaatcode wordt niet gekopieerd.** | De code blijft zichtbaar. Gebruik **Code kopiëren** of selecteer en kopieer de code handmatig. Open daarna de link voor GitHub-apparaatmachtiging. |
| **De cloudback-up ontbreekt.** | Open **Instellingen → Schleim-account**. Back-up maken kan alleen daar, niet in de Schleim-Store. |
| **Instellingen ontbreken na een browserwissel.** | Open **Instellingen → Schleim-account**, meld je aan met hetzelfde GitHub-account en kies **Cloudback-up herstellen**. |
| **Externe inhoud ontbreekt of blijft leeg.** | Controleer je internetverbinding. Sommige aanbieders blokkeren het insluiten van hun pagina's op andere websites. |
| **Installatie werkt niet in Chrome voor Android.** | Chrome voor Android ondersteunt geen gewone Chrome-extensies. Gebruik een Android-browser die extensies en rechtstreekse ZIP-import ondersteunt. |

## Meer hulp nodig?

Blijft het probleem bestaan, meld het dan via [GitHub Issues](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/issues). Beschrijf je browser, versie, de stappen en de foutmelding. Deel geen wachtwoorden of vertrouwelijke inloggegevens.
