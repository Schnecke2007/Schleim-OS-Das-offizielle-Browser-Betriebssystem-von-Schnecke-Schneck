# 🛠️ Schleim OS – Problemen oplossen

Hier vind je oplossingen voor veelvoorkomende problemen bij het installeren en gebruiken van Schleim OS.

| Probleem | Mogelijke oplossing |
|---|---|
| **Het nieuwe tabblad blijft ongewijzigd.** | Controleer bij `chrome://extensions` of Schleim OS is geïnstalleerd en ingeschakeld. Open daarna een nieuw tabblad. |
| **Chrome meldt een manifestfout.** | Pak het GitHub-ZIP-archief volledig uit en selecteer de map waarin `manifest.json` rechtstreeks staat. |
| **Er is een ZIP-bestand geselecteerd bij 'Uitgepakte extensie laden'.** | Deze functie verwacht een map. Pak het ZIP-bestand eerst uit en selecteer daarna de extensiemap. |
| **De verkeerde map is geselecteerd.** | Selecteer niet de bovenliggende repositorymap, maar de map waarin `manifest.json` rechtstreeks staat. |
| **Een andere extensie vervangt ook de nieuw-tabbladpagina.** | Schakel tijdelijk andere extensies uit die eveneens de nieuw-tabbladpagina vervangen. |
| **Wijzigingen worden niet weergegeven.** | Open `chrome://extensions`, klik bij Schleim OS op **Opnieuw laden** en open een nieuw tabblad. |
| **Externe inhoud ontbreekt of blijft leeg.** | Controleer je internetverbinding. Sommige aanbieders blokkeren het insluiten van hun pagina's op andere websites. |
| **Instellingen ontbreken na een browserwissel.** | Personalisatie wordt opgeslagen in het betreffende browserprofiel. Exporteer een JSON-back-up uit het oude profiel en importeer deze in het nieuwe profiel, als die functie beschikbaar is. |
| **Installatie werkt niet op Android.** | Chrome voor Android ondersteunt geen gewone desktopextensies. Gebruik hiervoor een aparte PWA of een browser die extensies ondersteunt. |

## Meer hulp nodig?

Blijft het probleem bestaan, meld het dan via [GitHub Issues](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/issues). Beschrijf welke browser en versie je gebruikt en welke stappen tot het probleem leiden. Deel geen wachtwoorden of vertrouwelijke inloggegevens.
