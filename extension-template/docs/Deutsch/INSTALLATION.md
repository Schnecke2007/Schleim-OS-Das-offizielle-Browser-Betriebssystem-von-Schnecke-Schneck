# Installation

1. Lade `Browser-OS-Extension-Template.zip` aus dem [neuesten Release](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/releases/latest/download/Schleim-OS-Extension-Template.zip).
2. **Entpacke die ZIP-Datei nicht.**
3. Öffne die Erweiterungsverwaltung eines Browsers mit lokaler ZIP-Importfunktion.
4. Aktiviere bei Bedarf den Entwicklermodus.
5. Wähle die ZIP-Datei über die Import-Funktion aus und bestätige.
6. Der Browser installiert oder aktualisiert die Erweiterung nach deiner Bestätigung.

Ein Download allein installiert nichts. Beim nächsten Update lädst du die neue Template-ZIP herunter und importierst sie erneut.

**Browser-Hinweis:** Normales Chrome für Android unterstützt keine Erweiterungen. Desktop-Chrome lädt über „Entpackte Erweiterung laden“ einen Ordner, nicht eine ZIP-Datei. Nutze für den ZIP-Import einen Browser, der diese Funktion ausdrücklich anbietet.
