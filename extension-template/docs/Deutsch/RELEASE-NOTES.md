# Versionshinweise – Browser OS Template 3.14.8

## Neue und verbesserte Funktionen

- Neutrale Browser-OS-Konto-Sitzung mit einmaliger Migration älterer Template-Sitzungen.
- Foto- und Video-Cloud verwendet einen frei konfigurierbaren privaten Repository-Namen.
- Hintergrund-Worker prüft denselben konfigurierten Medien-Repository-Namen wie Konto-, Medien- und Offscreen-Modul.
- Ältere Medienindizes bleiben lesbar; neue Indizes verwenden ein neutrales Browser-OS-Format.
- Vorlagen-IDs wurden von Schleim-spezifischen Demo-Namen auf neutrale Browser-OS-Bezeichnungen umgestellt.
- Store-Administration akzeptiert nur noch das neutrale Browser-Store-Format.

## Dokumentation

- Vollständige Konto- und Cloud-Anleitungen in Deutsch, Englisch und Niederländisch ergänzt.
- Leichte Sprache enthält jetzt Konto-/Cloud-Anleitungen in allen drei Sprachen.
- README-Links zeigen auf vorhandene Sprachdateien.
- Eine veraltete Sonos-spezifische Dokumentation wurde entfernt.
- Das Template-Release-Asset heißt jetzt `Browser-OS-Extension-Template.zip`.

## Installation und Updates

- Die Template-ZIP-Datei wird in kompatiblen Browsern direkt importiert und nicht entpackt.
- Der Download startet nicht automatisch die Installation. Import und Bestätigung erfolgen im Browser.
- Der Update-Center-Platzhalter lädt ausschließlich das Template-Asset aus dem eigenen konfigurierten Repository.
