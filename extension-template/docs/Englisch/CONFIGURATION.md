# Configuration

1. Open `manifest.json`. Change the name, short name, description and version.
2. Customize the sample name, profile text and example links in `scripts/app.js`.
3. Replace the images in `assets/demo/` and `assets/icons/`.
4. Set your GitHub username and repository name in `scripts/update-center.js`.
5. Configure your GitHub App ID, app link and private backup repository names in `scripts/browser-account.js`.
6. Set the same media repository name in `scripts/browser-media-cloud.js`.
7. Review the entries in `data/store-apps.json` and the Store links.

Use your own private repositories for personal backups and media. Never put GitHub App secrets, private keys or access tokens in extension code. Test the features with a test account.
