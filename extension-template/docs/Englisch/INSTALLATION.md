# Installation

1. Download `Browser-OS-Extension-Template.zip` from the [latest release](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/releases/latest/download/Schleim-OS-Extension-Template.zip).
2. **Do not extract the ZIP file.**
3. Open the extension manager in a browser that supports local ZIP import.
4. Enable Developer mode if required.
5. Select the ZIP file using the import option and confirm.
6. The browser installs or updates the extension after your confirmation.

Downloading alone does not install anything. For a later update, download the new Template ZIP and import it again.

**Browser note:** Standard Chrome for Android does not support extensions. Desktop Chrome's “Load unpacked” option loads a folder, not a ZIP file. Use a browser that explicitly supports ZIP import.
