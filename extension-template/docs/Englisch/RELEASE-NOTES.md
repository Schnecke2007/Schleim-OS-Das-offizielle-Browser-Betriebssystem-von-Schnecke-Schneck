# Release notes – Browser OS Template 3.14.8

## New and improved features

- Neutral Browser OS account session key with one-time migration from earlier template sessions.
- The photo and video cloud uses a configurable private repository name.
- The background worker validates the same configured media repository name as the account, media and offscreen modules.
- Existing media indexes remain readable; new indexes use a neutral Browser OS format.
- Template app IDs were changed from original-project demo names to neutral Browser OS names.
- Store administration now accepts only the neutral Browser Store format.

## Documentation

- Full account and cloud guides added in German, English and Dutch.
- Easy Language now includes account and cloud guides in all three languages.
- README links now point to files that exist in each language folder.
- An outdated Sonos-specific documentation file was removed.
- The template release asset is now named `Browser-OS-Extension-Template.zip`.

## Installation and updates

- Import the Template ZIP directly in compatible browsers. Do not extract it.
- Downloading does not install the template automatically. Import and confirmation remain browser actions.
- The template update center downloads only the template asset from your configured repository.
