# Release notes – Browser OS Template 3.14.9

## Documentation
- Language landing pages are clearly organized in German, English and Dutch.
- A central page links to all three Easy Language versions.
- New Easy Language configuration guides explain the GitHub App, private repositories and media cloud.
- General documentation pages now link to the matching language.

## Template
- Template filenames and modules were reviewed. They use neutral Browser OS names.
- Personal details, App IDs, GitHub names and repository names remain placeholders.
- Account, private settings backup, photo/video cloud, camera, Store and background upload remain included.
- The standalone file remains a sample demo without real GitHub sign-in or media uploads.

## Installation
- Template version 3.14.9.
- Release asset: `Browser-OS-Extension-Template.zip`.
- Do not extract the ZIP in compatible browsers; import and confirmation happen in the browser.
