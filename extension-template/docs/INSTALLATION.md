# Installation der Browser-OS-Vorlage

1. Lade die Template-ZIP-Datei aus dem neuesten Release herunter.
2. Entpacke die ZIP-Datei nicht.
3. Öffne die Erweiterungsverwaltung eines Browsers mit lokaler ZIP-Importfunktion.
4. Aktiviere bei Bedarf den Entwicklermodus.
5. Wähle die ZIP-Datei über die Importfunktion aus und bestätige.
6. Der Browser installiert oder aktualisiert die Erweiterung nach deiner Bestätigung.

Der Download allein installiert nichts. Normales Google Chrome für Android unterstützt keine Erweiterungen. Desktop-Chrome lädt im Entwicklermodus einen Ordner, aber keine ZIP-Datei direkt. Nutze einen Browser, der ZIP-Import ausdrücklich unterstützt.

Die ausführlichen Anleitungen in Deutsch, Englisch, Niederländisch und Leichter Sprache liegen in den Unterordnern dieses Verzeichnisses.
