# Einstellungen

Du kannst die Vorlage anpassen.

- Ändere den Namen in `manifest.json`.
- Ändere die Beispieltexte in `scripts/app.js`.
- Nutze deine eigenen Bilder.
- Trage dein eigenes GitHub-Projekt ein.
- Richte dein eigenes Konto ein.
- Richte einen privaten Speicher für Fotos und Videos ein.

Wichtig:
Teile keine Passwörter.
Teile keine geheimen Schlüssel.
Teste alles zuerst mit einem Testkonto.
