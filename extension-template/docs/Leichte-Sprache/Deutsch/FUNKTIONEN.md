# Funktionen

Die Vorlage hat mehrere Bereiche.

- Startseite mit Apps
- Suche und Einstellungen
- Browser Store
- Beispiel-Konto
- Private Foto- und Video-Cloud
- Kamera für Fotos und Videos
- Eine Demo-Webseite

Für das Konto brauchst du eine eigene GitHub App.
Für die Cloud brauchst du ein eigenes privates Repository.
Die Kamera braucht deine Erlaubnis.

Die Demo-Webseite ist keine Erweiterung.
Sie läuft direkt im Browser.
