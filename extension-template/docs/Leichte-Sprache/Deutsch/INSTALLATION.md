# Installation

So installierst du die Vorlage:

1. Lade die Template-ZIP-Datei herunter.
2. Entpacke die Datei nicht.
3. Öffne die Erweiterungsverwaltung.
4. Suche die Funktion für ZIP-Import.
5. Wähle die ZIP-Datei aus.
6. Bestätige die Installation.

Der Download installiert die Erweiterung nicht von allein.

Nicht jeder Browser kann ZIP-Dateien importieren.
Normales Chrome für Android unterstützt keine Erweiterungen.
