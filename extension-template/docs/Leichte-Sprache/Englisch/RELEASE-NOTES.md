# New version 3.14.8

## Changes

- The sample account now uses a neutral name.
- Old account sessions can be moved to the new storage key.
- You can set the name of the private photo and video repository.
- The background upload checks this name.
- New media indexes use a neutral name.
- Older media indexes can still be read.
- Template app IDs now use neutral names.

## Documentation

- Account and cloud guides are available in German, English and Dutch.
- Easy Language guides are also available in all three languages.
- README links were checked.
- An old Sonos document was removed.
- The Template ZIP is now named `Browser-OS-Extension-Template.zip`.

## Installation

Do not extract the ZIP file.
Import it in your browser.
The browser asks you to confirm.
