# New template version 3.14.9

## Documentation
- The guides are now sorted by language.
- There is an index for German, English and Dutch.
- There is a new simple guide for setup.

## Template
- File names are neutral.
- Your own details remain placeholders.
- The template still has account, cloud, photos, videos, camera, Store and background upload.
- The web demo uses sample data. It does not sign in to GitHub or upload media.

## Installation
The Template ZIP is still named `Browser-OS-Extension-Template.zip`.
Do not extract the ZIP file.
Import it in a browser that supports ZIP import.
Confirm the installation in the browser.
