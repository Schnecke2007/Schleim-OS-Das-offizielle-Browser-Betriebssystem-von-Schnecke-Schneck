# Functies

Het template heeft verschillende onderdelen.

- Startscherm met apps
- Zoeken en instellingen
- Browser Store
- Voorbeeldaccount
- Privé foto- en videocloud
- Camera voor foto's en video's
- Een demowebsite

Je hebt een eigen GitHub App nodig voor het account.
Je hebt een eigen privérepository nodig voor de cloud.
De camera heeft je toestemming nodig.

De demowebsite is geen extensie.
De website werkt rechtstreeks in je browser.
