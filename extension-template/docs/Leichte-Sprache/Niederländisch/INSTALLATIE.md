# Installatie

Volg deze stappen:

1. Download het Template-ZIP-bestand.
2. Pak het bestand niet uit.
3. Open het extensiebeheer.
4. Zoek de optie voor ZIP-import.
5. Selecteer het ZIP-bestand.
6. Bevestig de installatie.

Alleen downloaden installeert de extensie niet.

Niet elke browser kan ZIP-bestanden importeren.
De gewone Chrome voor Android ondersteunt geen extensies.
