# Instellingen

Je kunt het template aanpassen.

- Wijzig de naam in `manifest.json`.
- Wijzig de voorbeeldteksten in `scripts/app.js`.
- Gebruik je eigen afbeeldingen.
- Vul je eigen GitHub-project in.
- Stel je eigen account in.
- Stel privéopslag voor foto's en video's in.

Belangrijk:
Deel geen wachtwoorden.
Deel geen geheime sleutels.
Test alles eerst met een testaccount.
