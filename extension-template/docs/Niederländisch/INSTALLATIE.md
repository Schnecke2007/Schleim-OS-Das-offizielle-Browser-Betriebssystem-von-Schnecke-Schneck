# Installatie

1. Download `Browser-OS-Extension-Template.zip` uit de [nieuwste release](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/releases/latest/download/Schleim-OS-Extension-Template.zip).
2. **Pak het ZIP-bestand niet uit.**
3. Open het extensiebeheer in een browser die lokale ZIP-import ondersteunt.
4. Schakel indien nodig de ontwikkelaarsmodus in.
5. Selecteer het ZIP-bestand via de importfunctie en bevestig.
6. De browser installeert of werkt de extensie bij nadat je dit bevestigt.

Alleen downloaden installeert niets. Download voor een latere update het nieuwe Template-ZIP-bestand en importeer het opnieuw.

**Browserinformatie:** De gewone Chrome voor Android ondersteunt geen extensies. Desktop-Chrome laadt via “Load unpacked” een map en geen ZIP-bestand. Gebruik een browser die ZIP-import uitdrukkelijk ondersteunt.
