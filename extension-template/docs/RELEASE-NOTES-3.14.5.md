# Browser OS Extension Template 3.14.5

## Changes

- Updated the template documentation to use direct ZIP import in compatible Chromium-based browsers.
- Removed the instruction to extract the downloaded Template ZIP before installation.
- Clarified that the template's update center downloads only `Schleim-OS-Extension-Template.zip` from the repository configured in its placeholders.
- Clarified that importing and confirming an update remains a manual browser action.

## Important

This is the neutral Browser OS template. It does not modify or replace the original Schleim OS Extension package.
