# Browser OS Extension Template 3.14.8

## Deutsch
- Demo-IDs, Store-Bezeichnungen und Upload-Repository-Prüfungen sind neutralisiert.
- Ältere Konto-Sitzungen werden beim ersten Start auf den neutralen Speicherschlüssel migriert.
- Der Medien-Upload-Worker verwendet denselben konfigurierten Medien-Repository-Namen wie die übrigen Module.
- Ältere Medienindex-Formate bleiben lesbar.
- Konto-, Cloud-, Installations- und Technik-Dokumentation ist in Deutsch, Englisch, Niederländisch und Leichter Sprache in allen drei Sprachen vorhanden.
- Die veraltete Sonos-spezifische Dokumentation wurde durch allgemeine Hinweise zu externen Web-Apps ersetzt.
- Das Release-Paket heißt jetzt `Browser-OS-Extension-Template.zip`.

## English
- Demo IDs, Store labels and media repository checks are now neutral.
- Existing account sessions are migrated to the neutral storage key on first start.
- The media upload worker uses the same configured media repository name as the other modules.
- Older media-index formats remain readable.
- Account, cloud, installation and technical documentation is available in German, English, Dutch and Easy Language in all three languages.
- The outdated Sonos-specific documentation was replaced with general external web app guidance.
- The release package is now named `Browser-OS-Extension-Template.zip`.

## Nederlands
- Demo-ID's, Store-benamingen en controles van de mediarepository zijn nu neutraal.
- Bestaande accountsessies worden bij de eerste start overgezet naar de neutrale opslagsleutel.
- De media-uploadworker gebruikt dezelfde ingestelde mediarepository als de andere modules.
- Oudere media-indexformaten blijven leesbaar.
- Account-, cloud-, installatie- en technische documentatie is beschikbaar in Duits, Engels, Nederlands en eenvoudige taal in alle drie de talen.
- De verouderde Sonos-specifieke documentatie is vervangen door algemene uitleg over externe webapps.
- Het releasepakket heet nu `Browser-OS-Extension-Template.zip`.
