# Browser OS Extension Template 3.14.9

## Deutsch

### Dokumentation und Sprachen
- Die Dokumentations-Einstiegsseiten verweisen jetzt klar auf Deutsch, Englisch und Niederländisch.
- Eine zentrale Übersicht für Leichte Sprache enthält alle drei Sprachfassungen.
- Konfigurationshilfen in Leichter Sprache erklären die eigenen GitHub-, Konto-, Store- und Medienwerte in kurzen Schritten.
- Übergeordnete Konfigurations-, Konto-, Installations- und Technikseiten sind jetzt Sprach-Auswahlseiten statt einer Mischung einzelner Sprachen.

### Neutralität und Demo
- Dateinamen und Skriptmodule wurden geprüft. Die Template-Dateien verwenden neutrale Browser-OS-Namen; persönliche Original-Dateinamen wurden nicht gefunden.
- GitHub-Benutzernamen, Repository-Namen, App-ID, Profil, Links und rechtliche Angaben bleiben bewusst Platzhalter.
- Die installierbare Vorlage enthält Konto, privaten Einstellungs-Backup, Foto-/Video-Cloud, Kamera, Browser Store, Hintergrund-Upload und Update-Center.
- Die Standalone-Datei ist eine Demo. Sie verwendet Beispieldaten und führt keine echte GitHub-Anmeldung oder Medien-Uploads aus.

### Release und Installation
- Vorlagen-Version auf 3.14.9 erhöht.
- Das Release-Paket bleibt **Browser-OS-Extension-Template.zip**.
- In kompatiblen Browsern wird die ZIP-Datei unverändert importiert; der Browser verlangt eine manuelle Bestätigung.

## English

### Documentation and languages
- Documentation landing pages now link clearly to German, English and Dutch.
- A central Easy Language index links to all three language versions.
- Easy Language configuration guides explain the GitHub, account, Store and media placeholders in short steps.
- Top-level configuration, account, installation and technical pages are now language selectors instead of mixing languages.

### Neutral template and demo
- Template filenames and script modules were reviewed. They use neutral Browser OS names; no personal original-project filenames were found.
- GitHub username, repository names, App ID, profile, links and legal details remain intentional placeholders.
- The installable template includes account setup, private settings backup, photo/video cloud, camera, Browser Store, background upload and update center.
- The standalone file is a demo. It uses sample data and does not perform real GitHub sign-in or media uploads.

### Release and installation
- Template version increased to 3.14.9.
- The release asset remains **Browser-OS-Extension-Template.zip**.
- In compatible browsers, import the ZIP unchanged; the browser asks you to confirm the installation.
