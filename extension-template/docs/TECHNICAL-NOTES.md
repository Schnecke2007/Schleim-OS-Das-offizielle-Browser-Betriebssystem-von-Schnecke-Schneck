The installable template is a Manifest V3 Chromium extension. It includes a configurable GitHub account module, private settings backup, photo/video cloud, background upload worker, offscreen media processing, camera, Store and update center. The standalone HTML is a separate demo and does not perform real GitHub sign-in or upload media to a server.
