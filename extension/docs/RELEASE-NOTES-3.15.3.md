# Schleim OS 3.15.3 – mehrsprachige Dokumentation und aktualisierte Demo

## Deutsch

- Die Haupt-Extension wird auf Version 3.15.3 aktualisiert.
- Die Standalone-Demo wird mit den aktuellen Konto-, Foto-/Video-Cloud- und Kamera-Bereichen ausgeliefert.
- Die Template-Vorlage erhält neutrale Dateinamen, mehrsprachige Dokumentation und eine eigene Version 3.14.6.
- Die Template-Cloud übernimmt die mehrstufige Medienverarbeitung mit Hintergrund-Warteschlange, Fortschritt und Abschlussmeldung.
- Original-Extension und Template bleiben getrennte Pakete.

## English

- The main extension is updated to version 3.15.3.
- The standalone demo includes the account, photo/video cloud and camera areas.
- The template receives neutral file names, multilingual documentation and its own version 3.14.6.
- The template cloud includes multi-stage media processing with a background queue, progress and completion notifications.
- The original extension and the template remain separate packages.

## Nederlands

- De hoofdextensie wordt bijgewerkt naar versie 3.15.3.
- De zelfstandige demo bevat de onderdelen account, foto-/videocloud en camera.
- Het template krijgt neutrale bestandsnamen, meertalige documentatie en een eigen versie 3.14.6.
- De templatecloud krijgt mediaverwerking in meerdere stappen met een achtergrondwachtrij, voortgang en voltooiingsmelding.
- De oorspronkelijke extensie en het template blijven aparte pakketten.

## Browser compatibility

Direct ZIP import is only available in browsers that explicitly support it. Standard Chrome for Android does not support extensions; desktop Chrome's Developer mode loads a folder rather than a ZIP. The release ZIP must not be extracted when using a browser's ZIP-import function.
