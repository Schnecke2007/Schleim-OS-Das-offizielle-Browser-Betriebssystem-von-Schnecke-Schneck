## Browser- und Installationshinweise

Die Original-Extension und das Template werden als getrennte ZIP-Dateien veröffentlicht. In Browsern mit lokalem ZIP-Import bleibt die ZIP-Datei unverändert; Import und Bestätigung werden manuell im Browser gestartet. Normales Google Chrome für Android unterstützt keine Erweiterungen. Desktop-Chrome lädt im Entwicklermodus entpackte Ordner und unterstützt keinen direkten ZIP-Import.

The original extension and template are published as separate ZIP files. In browsers that support local ZIP import, keep the ZIP unchanged; start the import and confirmation manually in the browser. Standard Google Chrome for Android does not support extensions. Desktop Chrome's Developer mode loads extracted folders and does not support direct ZIP import.

De oorspronkelijke extensie en het template worden als aparte ZIP-bestanden gepubliceerd. In browsers met lokale ZIP-import blijft het ZIP-bestand ongewijzigd; het importeren en bevestigen start je handmatig in de browser. De gewone Google Chrome voor Android ondersteunt geen extensies. Desktop-Chrome laadt uitgepakte mappen in de ontwikkelaarsmodus en ondersteunt geen rechtstreekse ZIP-import.
