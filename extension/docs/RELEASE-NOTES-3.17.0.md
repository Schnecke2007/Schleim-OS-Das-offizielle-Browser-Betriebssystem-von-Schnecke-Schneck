# Schleim OS 3.17.0 – Browser-Kontextmenü, Drucken und Erweiterungen

## Schleim Browser für Android – neue Funktionen

- **Kontextmenü durch langes Drücken:** Ein langer Druck auf einen Link, ein Bild, ein Video oder eine Audiodatei öffnet passende Browseraktionen.
- Links können in einem neuen Tab geöffnet, heruntergeladen oder als Adresse kopiert werden.
- Bilder, Video- und Audioquellen können – sofern die Webseite eine direkte HTTP(S)-Adresse bereitstellt – geöffnet, heruntergeladen oder als Adresse kopiert werden.
- **Seite drucken:** Über das Browser-Menü und das Kontextmenü lässt sich die aktuelle Webseite an Androids Drucksystem übergeben. Dort kann ein Drucker oder „Als PDF speichern“ ausgewählt werden.
- **Erweiterungen öffnen:** Im Erweiterungsmanager erscheint „Öffnen“, wenn ein Add-on eine Optionsseite bereitstellt. Für die integrierte Schleim-OS-Erweiterung führt die Aktion zur Schleim-OS-Startseite.

## Hinweise und Grenzen

- Bei geschützten, dynamisch erzeugten oder blob-basierten Dateien hängt die Downloadmöglichkeit von der von der Webseite bereitgestellten Adresse ab. Manche Streaming- und DRM-Inhalte lassen sich nicht als einzelne Datei herunterladen.
- Nicht jede Erweiterung besitzt eine Optionsseite. In diesem Fall wird kein „Öffnen“-Button angezeigt.
- Die Android-App bleibt eine Alpha-Version. Die Kamera- und Mikrofonaufnahme sind weiterhin deaktiviert.
- Die APK wird als Debug-Build veröffentlicht. Je nach Signaturschlüssel kann ein Update die vorherige App-Deinstallation erfordern.

## Versionsinformationen

- Android-App: **Schleim Browser 0.1.0-alpha23**
- Android-Version: mindestens 8.0 (API 26), ARM64
- Browser-Engine: Mozilla GeckoView
