# Browser OS – Template

This directory contains a separate, neutral copy of the browser extension. The original project in `extension/` is not modified by this template.

## Download only the template

[**Download the template ZIP**](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/archive/refs/heads/browser-os-template.zip) · [Browse template files](https://github.com/Schnecke2007/Schleim-OS-Das-offizielle-Browser-Betriebssystem-von-Schnecke-Schneck/tree/main/template)

The ZIP branch contains only the template files at its root. You do not need to download the full original project.

## Quick start

1. Download and extract the template ZIP.
2. Read [CONFIGURATION.md](CONFIGURATION.md) and replace the setup placeholders.
3. Open your Chromium browser's extension manager and enable Developer mode.
4. Select **Load unpacked** and choose the extracted template folder.
5. Open a new tab and test the demo interface.

## Included

- Full Manifest V3 extension structure
- New-tab interface, app navigation and responsive layouts
- Personalization, store catalog and sample ratings
- Optional GitHub account and private backup/photo-video cloud modules
- Optional local AI image-description integration
- Standalone demo, tests and technical documentation
